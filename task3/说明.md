# 第三题 Redis 上机实验 — 说明

## 脚本作用

`main.py` 连接本地 Redis，依次演示四种基本数据类型的典型用法：

1. **Hash** — 学生信息：创建多字段 Hash，修改 status，按字段读取，hgetall 验证字段保留。
2. **Set** — 已完成章节：连续 sadd 四条（含重复 CH02），scard 观察去重，sismember 判断成员。
3. **Sorted Set** — 成绩排行：zadd 五人成绩，zrevrange 输出前 3，zincrby 给本人 +20 分，zrevrank 计算名次。
4. **String + TTL** — 会话键：set 带 ex=5 创建会话，ttl 查看剩余时间，sleep 6 后验证自动过期。
5. **TYPE 核验** — 输出四类键的实际类型，并各用一句话说明选型理由。

所有键统一使用前缀 `exam:12403030119:`。

## 运行方法

```bash
# 确保本地 Redis 已启动 (端口 6379)
python3 main.py
```

## 依赖

- Python 3.8+
- redis-py 8.x（`pip install redis`）

## 连接常量（可在源码顶部修改）

```python
HOST = "localhost"
PORT = 6379
```

无密码、无 db 选择，连接后默认使用 db 0。
