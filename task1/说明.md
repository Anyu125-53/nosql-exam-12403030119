# 第一题说明（MongoDB 课程信息查询与维护）

## 文件构成
- `init.py`：初始化脚本，可独立运行。连接个人数据库 `exam_12403030119`，
  先 `deleteMany({})` 清空 `courses` 集合，再 `insertMany` 插入三门课程文档
  （课程编号 COURSE-12403030119-01 / -02 / -03，字段与原题 mongosh 示例一致）。
- `main.py`：业务操作脚本。**不调用 init、不重新初始化数据**，可重复执行。
  依次完成：
  1. 查询 teacher=张老师 且 status=OPEN 的课程，章节数量用投影表达式
     `{ $size: "$chapters" }` 在服务端计算（不写死）；
  2. 用 `$set` 配合 `arrayFilters`（定位 chapters 中 chapterId=CH02 的元素）
     把第01门课 CH02 标题改为 `Redis基础与应用-19`（S=19），保留其他字段与章节；
  3. 用 `$addToSet` 连续两次向第01门课追加
     `{chapterId:"CH03", title:"Redis高级操作", hours:3}`（hours=2+A=3），
     按整个元素去重，CH03 最终只出现一次；
  4. 核验 CH02 新标题、CH03 数量、章节总数、teacher/status 是否保持原值，
     并输出“为何适合局部更新”的书面回答。
- `result.txt`：四步预期输出（本沙箱无库，均标注“预期/待真机核验”，未伪造实测）。

## 运行顺序
```bash
python3 init.py      # 先初始化（仅执行一次即可）
python3 main.py      # 再执行业务操作，可重复执行
```

## 依赖与连接常量
- 依赖：`pymongo`（本机为 4.19.0）。
- 连接常量写在两个脚本顶部：
  - `HOST = "localhost"`
  - `PORT = 27017`
  - `DB_NAME = "exam_12403030119"`
- 源码中不含任何账号/密码凭据；如需连有鉴权或远程集群，
  仅修改顶部连接常量即可（可改用 `MongoClient("mongodb://host:27017/")`）。
